# Historical repository documents

These documents came from the **RC50-era GitHub source baseline**. Their bytes and Git lineage are preserved in this archive rather than scattered across the repository root.

This collection includes RC32–RC50 release notes, Windows test guides, old naming conventions, source-scan output, roadmaps and the original work register. Some document names describe later planned work; names alone are **not proof of an installed or certified release**.

Check `config/release-candidate.json` in the active source branch for the source candidate actually tracked. New release notes should be stored under documentation or as verified GitHub Release artifacts, not added as dozens of root files.
