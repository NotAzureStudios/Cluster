# Polish & Enhancement Phase E

Phase E turns Notifications into a triage surface and Activity into an interpretable event stream.

Notifications preserve search, digest, severity, read/unread, snooze, dismiss, source rules, and per-project policies while adding date/project/category grouping, priority ordering, direct project policy changes, and one-click mark-all-read handling.

Activity classifies events as Person, Automation, or System and makes that classification filterable and visible in the stream and event detail. Existing project, time, entity, action, presence, project-status, and audit-risk views remain intact.
