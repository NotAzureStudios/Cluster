# Polish & Enhancement Phase C — Home + My Work

Phase C separates the two personal surfaces by intent. Home is the glanceable daily brief; My Work is the execution queue.

## Home

- Loads the signed-in user's team assignment model.
- Shows overdue, high/urgent, scheduled-today, and total assigned pressure.
- Ranks a bounded next-up list by priority and due date.
- Keeps today's schedule beside the work queue.
- Jumps directly into the matching board where possible.
- Retains resume context, attention signals, project readiness, team pulse, and time tracking.

## My Work

- Adds a five-item daily focus plan.
- Separates overdue, due-today, high/urgent, and unscheduled queue health.
- Preserves full assigned-work search, project health, related activity, and stale-data recovery.
- Adds direct Timeline and Scheduler access.

The phase intentionally avoids duplicating full project management on Home. Home summarizes; My Work executes; Projects remains the system of record.
