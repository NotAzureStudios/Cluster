# Polish + Enhancement Phase F — Users, Teams, and Profiles

Phase F turns People into an operating view rather than a static directory.

## Contract

- People summary exposes availability, aggregate capacity, workload pressure, and profile-completeness gaps.
- Selected profiles expose projects, assigned cards, overdue/high-priority pressure, direct-report context, recent activity, and profile completion.
- Access is a first-class profile view with tool permission levels and bounded account posture.
- Sensitive contact data continues to use the existing privacy boundary.
- Project assignments remain directly navigable from People.
- Web and Desktop continue to use the same shared renderer.
