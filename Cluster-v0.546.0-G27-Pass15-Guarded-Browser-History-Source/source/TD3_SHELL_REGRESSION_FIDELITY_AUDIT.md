# Cluster v0.546.0 | TD3 Shell and Identity Regression Audit

**Source baseline:** TD3 Pass 11. **Scope:** Implementation fidelity and source/fixture alignment, not release certification.

## Confirmed from source
- My Work is rendered by `ApplicationProjectTabs.tsx` when allowed by tool permissions.
- The personal Tickets menu is rendered by that taskbar when Tickets is enabled and authorized.
- `TaskbarTransferCenter` handles browser uploads/download handoffs and native transfer activity; its icon is part of taskbar utilities.
- `TaskbarProjectTabs` renders project objects from `openProjectIds`. It does not insert People tabs or other workspace tabs. People remains main sidebar/account navigation. Optional mixed-workspace taskbar is **not implemented**.
- `PresenceAvatar` already renders the separate activity/presence indicator and `--user-avatar-accent`; a rounded-square avatar style exists. The Pass 11 gallery was an illustrative fixture that replaced it with a round fake avatar.
- Taskbar has a Search command trigger, and the Command Palette has a separate modal search field. The requested expanding tab-to-search interaction is **not implemented** yet.

## Fixed in this source update
- Pass 11 source-based visual fixture now keeps My Work, Tickets, Transfer Center, Inbox, Quick Create, and one Search trigger rather than hiding/doubling them.
- Mock taskbar represents project tabs only; it no longer substitutes the name of each main workspace as a fake tab.
- Mock People avatars now show rounded-square shapes, separate per-user color borders, and separate activity dots alongside availability chips.
- Actual Command Palette input zone now has an explicit material/background treatment and a distinct focus state.
- Added 18 executable shell/preview fidelity regression assertions to keep mockups from silently dropping real controls.

## Outstanding implementation, not certification
1. Replace the modal search presentation with a **single actual taskbar search field** that animates the project tab strip out and in. Results should appear in a taskbar-anchored drawer without duplicating search fields. Reuse Command Palette's existing ranking, permissions, keyboard shortcuts, and result actions.
2. Implement an optional personal setting for mixed workspace tabs **only if deliberately accepted**; default remains project-only. People, Tickets, My Work, and Transfer Center remain separate navigational/utility entries.
3. Audit visibility at dense widths: controls should overflow intelligently rather than vanish under the appearance of having been removed.
4. Future preview batches must be real mounted app renders where feasible; static fixture previews are labeled as such and tested for shell/identity fidelity.
