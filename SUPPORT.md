# Internal support

Cluster is an internal Azure Studios tool. It does not provide public support for arbitrary installations.

- **Bug or regression:** Create a private issue in this repository with the affected feature, exact candidate version, reproduction steps, sanitized logs and expected versus actual results.
- **Security issue:** Report privately to the authorized maintainers following [SECURITY.md](SECURITY.md). Do not post sensitive details in an ordinary issue.
- **Installer or server failure:** Include the Windows version, Cluster candidate, stage of startup/install, relevant redacted diagnostics and whether the failure affects data or connectivity.
- **Development:** Refer to [local setup](docs/development/LOCAL_SETUP.md), [Git workflow](docs/development/GIT_WORKFLOW.md) and [README](README.md).

Source-only test results do not establish that a Windows installation is supported or certified.
